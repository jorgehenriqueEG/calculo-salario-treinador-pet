# calculo-salario-treinador-pet
## Descrição do Problema
Calcular o salário de um treinador de cães com base no número de sessões e no tipo de raça atendida.
## Requisitos
- Sessões de raças pequenas valem 1x
- Sessões de raças médias valem 1.5x
- Sessões de raças grandes valem 2x
- Valor base por hora é 50 reais
## Exemplo de Uso
Entrada: 4 sessões pequenas, 2 médias, 1 grande
Saída: Salário total: 420.0
